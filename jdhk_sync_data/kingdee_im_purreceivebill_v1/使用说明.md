数据库表结构
拆分为两张表，通过 bill_id 关联：


kingdee_purreceivebill          (主表，单据头)
  id PK ← 38 个字段（单据状态、日期、汇率、供应商、采购员等）

kingdee_purreceivebill_entry    (明细表，单据行)
  id PK, bill_id FK → 约 120 个字段
  含：物料/仓库/数量/价格/税额/入库/对账/验收/质检/退货/损耗/委外/合同/来源单等
使用方式

# 全量同步
python main.py

# 按修改时间增量
python main.py --modifytime_start "2024-06-01 00:00:00" --modifytime_end "2024-06-30 23:59:59"

# 按业务日期
python main.py --biztime_start "2024-06-01" --biztime_end "2024-06-30"

# 过滤已审核单据
python main.py --billstatus C
